# 📊 MoneyReg - Harcama Takip Uygulaması

MoneyReg, kişisel ve ortak harcamalarınızı kolayca takip etmenizi sağlayan, çoklu para birimi destekli, çevrimdışı (offline) çalışabilen modern bir harcama takip uygulamasıdır.

## ✨ Özellikler
*   **Çoklu Para Birimi:** TL, USD ve EUR cinsinden harcama ekleyin, anlık kurlarla takip edin.
*   **Ortak Harcamalar:** Gruplar oluşturun, arkadaşlarınızla harcamaları paylaşın ve borç/alacak durumlarını görün.
*   **Fiş Okuma (OCR):** Fişlerinizin fotoğrafını çekin, yapay zeka tutarı ve kategoriyi otomatik doldursun.
*   **Çevrimdışı Çalışma:** İnternet olmasa bile harcama ekleyin, bağlantı gelince otomatik senkronize olsun.
*   **Detaylı Raporlar:** Haftalık, aylık ve yıllık harcama alışkanlıklarınızı analiz edin.
*   **Taksitli Harcamalar:** Taksitli alışverişlerinizi sisteme girin, gelecek dönem yüklerinizi görün.
